## 3. 漏洞根因 + 修复

### 4.A risk_manager multi-symbol capital reference
- Root cause: 8c41c62 risk_manager check_hard_stop / check_position_limit / check_daily_loss
  用 config.TOTAL_CAPITAL 作 baseline. Sub-bot allocated_capital ($5k) << TOTAL ($10k),
  启动即触发 50% 虚假亏损 hard_stop.
- Fix: 加 _capital_reference() helper, 多 symbol 传 allocated_capital. 多标的模式委托
  给 account_risk (check_hard_stop / check_daily_loss / is_hard_stopped). 单标的 fallback 不变.
- Verify: backtest UVXY +82.81% (单标退化) + multi +201.69% (Gate PASS)
- Commits: 61ca298 + 11cfb72

### 4.B entry_filter getattr fallback dead code
- Root cause: `getattr(config, "ENTRY_MAX_ADX_SLOPE", -1.0)`, fallback 与 default 不一致.
- Fix: 改为直接 `config.ENTRY_MAX_ADX_SLOPE`.
- Verify: test.py 全绿 (无回归), backtest 不变.
- Commit: db7a4ea

### 4.C config.py stale comment
- Root cause: 注释"默认改 -1000 (关闭)" 与实际 default -0.5 矛盾.
- Fix: 删除. 加 ENTRY_MAX_ADX_SLOPE 反测据注释 (-1.0=+0.28% / -0.5=+82.81%).
- Commit: db7a4ea + b388f7b

### 4.D V49 → 8c41c62 -27pp 回归
- 见 `reports/v49_27pp_regression.md`
- **First bad commit**: `e369447` ("WAITING_ENTRY 节拍与 STRATEGY_INTERVAL 解耦")
- Root cause: bar-by-bar backtest 模式下, scanning→waiting→immediate-entry 同 bar 评估 + 非交易时段重置 timeout counter 导致质量退化
- 未修, 标记 follow-up (spec §7)
- Commit: 78fa845 (report only)

### 4.E GridBot allocated_capital (plan-discovered)
- Root cause: 8c41c62 GridBot 不接 allocated_capital, sub-bot sizing 用全账户.
- Fix: 加 minimal `allocated_capital`/`symbol`/`capital_provider` kwargs + `_capital()` helper + `@property symbol`.
- Verify: backtest UVXY +82.81% (单标等价), multi +201.69% (Gate PASS)
- Commits: b388f7b + 92bf96a

### Phase 6 plan-discovered: grid_engine.py wall-clock 违规
- Root cause: 3 处 `datetime.now()` fallback 在 grid_engine.py 业务模块 (CLAUDE.md §9 死规矩).
- Fix: 强制 explicit `current_time` 参数, 移除 fallback. Test 调整 3 处.
- Commit: cbdb210
